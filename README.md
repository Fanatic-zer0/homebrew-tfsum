# homebrew-tfsum

Homebrew tap for [tfsum](https://github.com/Fanatic-zer0/tfsum).

```sh
brew tap Fanatic-zer0/tfsum
brew install tfsum
```

`Formula/tfsum.rb` is updated automatically by tfsum's release workflow
(`homebrew-tap` job in `.github/workflows/ci.yml`) whenever a new `v*` tag
is pushed. Do not edit it by hand — changes will be overwritten on the next
release.
